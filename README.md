# 02452-ML-Project
This repository contains our code for the ML project as part of the DTU course [02452 Machine Learning](https://kurser.dtu.dk/course/02452) (Fall 2025).

### Part 1
The first part of the project consists mainly of an [Exploratory Data Analysis](https://github.com/krusand/02452-ML-Project/blob/main/EDA.ipynb) and a [PCA Analysis](https://github.com/krusand/02452-ML-Project/blob/main/pca_analysis.ipynb), which are contained in notebooks. 

The [main_script.py](https://github.com/krusand/02452-ML-Project/blob/main/main_script.py) generates a summary of the dataset attributes as well as all the figures contained in the [figures](https://github.com/krusand/02452-ML-Project/tree/main/figures) folder. 

Part 1 of the project is handed in on the 2nd of October, 2025.
